# Tipi Restructuring Plan

## Core Requirements & Objectives

1. **Branding & UI/UX**
   - Redesign with a clean, simple, and static layout (no complex animations for now).
   - Ensure a typical, intuitive mobile app layout (prioritizing mobile/portable use).
   - Improve branding to feel cohesive and professional.

2. **Scoped Feature Set**
   - Budget grocery running tool for the Philippines using the World Food Programme (WFP) prices dataset.
   - Limit the database scope to: **Davao del Norte (Panabo and Tagum City only)**.
   - Refactor/fix bad logic and simplify flow.

3. **Project & Folder Reorganization**
   - Reorganize the folder structure to be clean and intuitive (especially for web developers).
   - Clean up and remove unused files and dead code.

4. **Tipi App Backend Reset (`backend/` folder)**
   - Reset the backend to 0 (clean slate).
   - We are migrating away from Supabase's cloud backend to our own custom, lightweight API backend.
   - Containerize using **Docker** for deployment on **Render** (Free Web Service tier).
   - Database: Use a free **Neon PostgreSQL** server database.
   - Handles:
     - User authentication & session management.
     - Profile storage, budget goals, and saved stats.
     - Grocery runs header records and individual shopping items.

5. **Dataset Fetching API (`dataset/` folder)**
   - Create a separate backend website/layer inside the folder `dataset/` (pure backend, no UI complexity) to fetch the dataset.
   - Containerize using **Docker** for deployment on **Render** (Free Web Service tier).
   - Exposes:
     - `GET /api/version`: Returns the version/date of the current dataset.
     - `GET /api/prices`: Returns the filtered list of Panabo/Tagum food prices.
     - `POST /api/update`: Triggers an update/import of the latest dataset.

## Planned Folder Structure
```
tipi/
├── backend/             # Main Tipi REST API backend (Dockerized for Render)
│   ├── src/             # Authentication, Profiles, and Grocery Runs logic
│   ├── Dockerfile
│   └── docker-compose.yml
├── dataset/             # Pure backend layer for price data (Dockerized for Render)
│   ├── src/             # Parsers & sync logic for Davao del Norte WFP dataset
│   ├── data/            # Scoped CSV/JSON data
│   ├── Dockerfile
│   └── docker-compose.yml
├── lib/                 # Flutter mobile client
│   ├── config/          # App constants, API endpoints, theme data
│   ├── models/          # Data models (e.g., GroceryItem, Run, User)
│   ├── services/        # Clean API client services
│   ├── views/           # UI Screens & Layouts
│   │   ├── auth/        # Login/Register views
│   │   ├── home/        # Main dashboard
│   │   ├── runs/        # Grocery running flow
│   │   └── profile/     # User profile settings
│   ├── widgets/         # Shared, reusable UI components
│   └── main.dart        # Entry point
└── pubspec.yaml
```
